# NodeBar

macOS 菜单栏里的本地 Node 服务管理器。双击 `build/NodeBar.app`，点击菜单栏的图标或旁边的数字即可打开面板。数字表示监听 TCP 的 Node 进程数，每四秒更新一次。

- 点击“选择监控目录”可以选择单个项目或工作区。运行中列表按进程工作目录筛选，已停止列表也会列出目录内通过 package.json 发现的项目。发现过程跳过隐藏目录、构建产物与 node_modules。新增项目后可点刷新重新扫描；“显示全部”可清除筛选。目录选择会保留到下次启动。
- 打开面板后，运行中标签页直接显示项目、工作目录和端口。点击目录可在 Finder 中打开，悬停服务卡片可查看 PID。
- 点击“局域网打开”会直接用浏览器访问对应 IP 和端口，默认协议为 HTTP。对于只绑定回环地址的服务，“本机打开”会按需通过本机局域网 IPv4 地址转发，仅接受这台 Mac 的连接。原端口无法使用时，面板会更新为实际转发端口。退出 NodeBar 将关闭转发。绑定全部 IPv6 地址时，IPv4 局域网入口取决于服务是否启用了双栈。局域网访问也受 macOS 防火墙影响。
- 点击卡片上的“停止”会立即向该监听进程发送 SIGTERM。外层守护程序可能会将它重新拉起。
- “已停止”标签页中的项目记录保存在本机。停止后可选择工作目录的 package.json 脚本启动。包管理器由 packageManager 或锁文件确定，启动日志在 ~/Library/Logs/NodeBar。原终端临时设置的环境变量、命令参数需要在项目脚本或配置中提供。
- 退出 NodeBar 后，运行中的服务继续运行。工具只监测当前用户的 Node TCP 服务，纯后台任务和容器内进程不在列表中。

## 构建

安装 Xcode Command Line Tools 后，在本目录运行 `./build.sh`。产物位于 `build/NodeBar.app`，可移动到“应用程序”。要登录后自动启动，可在 macOS 的“系统设置 → 通用 → 登录项与扩展”中添加该应用。

命令行运行 `build/NodeBar.app/Contents/MacOS/NodeBar --list` 可查看一次扫描结果。
